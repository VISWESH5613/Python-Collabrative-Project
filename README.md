## Files
- `mypython.py` — Complete conflict-free timetable scheduler with Multi-Factor Decision Pointer, walking distance formula `(Block Delta * 10) + (Floor Delta * 3)`, 2-hour continuous lab allocation, student roll-number batch lookup (`E26STU00001`–`E26STU10000`), and CSV/TXT export.
- `rooms.csv` — 13 campus classrooms and labs across Block A, Block B, Block C, and Lab Block.
- `courses.csv` — 8 courses including 1-hour lectures/tutorials and 2-hour lab sessions.
- `batches.csv` — 24 student batches (`B1`–`B24`) covering 10,000 student enrollment numbers.

## How to Run
```bash
python mypython.py
```
